# Indice di Rarefazione
## Principio

La forza di un [dominio](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/cosmologia/dominio.md) è determinata dal suo **indice di rarefazione** rispetto a un concetto originario. Più l'interpretazione è stratificata e densa (più "rarefatta" dal concetto puro), più il dominio è forte.

Un dominio esiste solo in relazione al dominio che lo contiene: la sua forza non è assoluta ma relativa al contenitore.

## Struttura ad Albero

I domini formano una gerarchia innestata:

```
CALDO/FREDDO          ← archetipo puro (massima forza)
├── Fuoco             ← dominio derivato
├── Ghiaccio           ← dominio derivato
├── Acqua              ← dominio derivato (a cavallo tra più archetipi)
├── Sole               ← dominio derivato
└── Fulmine            ← dominio a cavallo: CALDO/FREDDO + ENERGIA
```

Un dominio "a cavallo" appartiene a più archetipi simultaneamente — come il fulmine che è sia caldo/freddo che energia.

## Implicazioni

- I domini più fondamentali sono gli archetipi più puri (es. caldo/freddo)
- Un dominio può esistere solo all'interno di un altro dominio o archetipo
- La gerarchia tra gli dei rispecchia questa struttura
- L'indice di rarefazione cresce con l'uso e l'interpretazione collettiva
- Struttura analoga alle galassie (gerarchia cosmologica)
- **Rarefazione minima** = concetto più puro = [punti-di-esclusione](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/cosmologia/punti-di-esclusione.md) (ascensione a divinità ma isolamento totale)
- **Rarefazione massima** = concetto più diluito, più connessioni con altri domini

## Relazioni

- Misura la forza di: [dominio](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/cosmologia/dominio.md)
- Struttura collegata a: [paradigma](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/magia/paradigma.md) (più interpretazione = più forza)
- Fondamento della: gerarchia degli dei
