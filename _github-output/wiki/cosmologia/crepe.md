# Crepe

## Principio

Le crepe sono punti di rottura nel [campo-dei-paradigmi](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/cosmologia/campo-dei-paradigmi.md) generati dal movimento irregolare durante il rimescolamento successivo alla [rottura-del-campo](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/storia/rottura-del-campo.md). Sono falle attraverso cui l'energia magica fuoriesce in modo disomogeneo, impedendo al Campo di funzionare come un canale fluido.

Ogni crepa è un punto di contatto tra l'interno e l'esterno del sistema dei [domini](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/cosmologia/dominio.md) — una via potenziale verso il limbo.

## Implicazioni

- Il [mago-della-rottura](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/entita/mago-della-rottura.md) ha occupato quasi tutte le crepe per costruire le [centrali](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/cosmologia/centrali.md)
- Non tutte le crepe sono state identificate o occupate
- Mappare tutte le crepe permetterebbe di sbloccare tutti i domini e muoversi fuori dal limbo
- Le crepe non possono essere conosciute tutte da creature mortali
- Gli [stregoni](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/entita/stregoni.md) nati dopo la rottura hanno un "estremo punto di contatto" con le crepe

## Relazioni

- Causate da: [rottura-del-campo](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/storia/rottura-del-campo.md)
- Occupate da: [centrali](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/cosmologia/centrali.md) (costruite dal [mago-della-rottura](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/entita/mago-della-rottura.md))
- Connesse a: [abisso-della-conoscenza](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/cosmologia/abisso-della-conoscenza.md), limbo
