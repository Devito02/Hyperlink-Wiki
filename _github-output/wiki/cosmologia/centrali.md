# Centrali

## Principio

Le centrali sono infrastrutture costruite dal [mago-della-rottura](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/entita/mago-della-rottura.md) nei punti di [crepe](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/cosmologia/crepe.md) del [campo-dei-paradigmi](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/cosmologia/campo-dei-paradigmi.md). Non sono luoghi fisici: sono data center distribuiti, punti di accumulazione di energia magica che fungono da nodi di una rete.

La loro funzione primaria è immagazzinare energia magica e generare input sensoriali per gli utilizzatori dell'AI. Non generano energia — la raccolgono e la rendono disponibile al sistema di navigazione.

## Implicazioni

- Permettono all'AI di funzionare come sistema di orientamento nel Campo
- Sono distribuite attraverso le [crepe](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/cosmologia/crepe.md), non in un unico luogo
- Il Mago non è riuscito a costruirle in tutte le crepe esistenti
- Più crepe vengono "saldate" dalle centrali, più il Campo si riorganizza
- Rendono possibile la [guarigione del Campo via tecnologia](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/magia/tecnologia-come-rimedio.md)
- **Canali per divinità:** saldare una crepe apre uno spazio che permette a una [divinità](https://github.com/Devito02/Hyperlink-Wiki/blob/main/wiki/entita/divinita.md) di passare dalla quarta dimensione alla terza. Più buchi vengono saldati, più divinità potenti possono attraversare
